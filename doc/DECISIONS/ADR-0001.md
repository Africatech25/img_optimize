# ADR-0001 — Choix architecture stateless

## Statut : Accepté

## Contexte
Le projet img_optimize vise à optimiser des images à la volée, sans stockage persistant, pour simplifier la sécurité et l’exploitation.

## Décision
- Le backend ne stocke aucune image ni métadonnée : tout est traité en mémoire et retourné immédiatement.
- Pas de base de données ni de filesystem persistant.

## Conséquences
+ Sécurité renforcée (pas de fuite de données persistantes)
+ Exploitation simplifiée (pas de backup, pas de migration)
- Pas d’historique ni de suivi des traitements
- Limite la possibilité de fonctionnalités avancées (historique, stats)

## Alternatives rejetées
- Stockage temporaire sur disque : complexité et risques accrus
- Base de données pour logs : surdimensionné pour le MVP
